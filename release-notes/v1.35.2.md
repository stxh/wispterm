# WispTerm v1.35.2

> Patch release fixing copied text from wrapped terminal lines and multiline
> Agent commands in SSH/WSL sessions. No configuration migration is required.

## Fixed

- **Copying visually wrapped lines (#595).** Terminal-width wrapping no longer
  inserts extra line breaks into copied text. WispTerm now uses Ghostty's
  selection formatter so visual soft wraps are joined while real line breaks
  remain intact.
- **Multiline Agent commands over SSH/WSL.** The session command wrapper now
  removes trailing CR/LF before appending its status sentinel. Multiline scripts
  remain supported without producing an invalid standalone semicolon in the
  remote shell.

## Compatibility

- Existing settings and workflows require no changes.
- This is a desktop-only release; WispTerm Remote web console versions are not
  changed.

# WispTerm v1.35.2（中文）

> 本次补丁发布修复终端折行文本复制，以及 SSH/WSL 会话中的 Agent 多行命令；
> 无需迁移配置。

## 修复

- **复制视觉折行文本（#595）。** 终端宽度造成的视觉折行不再作为额外换行写入
  剪贴板。WispTerm 现在使用 Ghostty 的选择文本格式化逻辑，自动拼接软换行，
  同时保留真实换行。
- **SSH/WSL Agent 多行命令。** 会话命令封装器会先移除命令末尾的 CR/LF，
  再追加状态标记。远程多行脚本仍然可用，也不会再向 shell 生成独立且非法的
  分号。

## 兼容性

- 现有设置与工作流无需修改。
- 本次仅发布桌面应用，不调整 WispTerm Remote 网页控制台版本。
