# WispTerm v1.35.4

> Patch release adding a one-click Windows replace script for portable zips.
> No configuration migration is required.

## Added

- **Windows click-to-replace script.** Unzip a portable release and
  double-click `Replace-WispTerm.cmd`. It overwrites the Start-menu install
  (or copies into `%LOCALAPPDATA%\Programs\WispTerm` and creates that shortcut
  when none exists), then starts the new build. Portable config next to the
  exe is left untouched.

## Compatibility

- Existing settings and workflows require no changes.
- This is a desktop-only release; WispTerm Remote web console versions are not
  changed.

# WispTerm v1.35.4（中文）

> 本次补丁发布为 Windows 便携包增加一键替换脚本；无需迁移配置。

## 新增

- **Windows 一键替换脚本。** 解压便携包后双击 `Replace-WispTerm.cmd`。脚本会
  按开始菜单快捷方式覆盖现有安装；如果还没有快捷方式，则复制到
  `%LOCALAPPDATA%\Programs\WispTerm` 并创建开始菜单项，然后启动新版本。
  exe 旁边的便携配置不会被覆盖。

## 兼容性

- 现有设置与工作流无需修改。
- 本次仅发布桌面应用，不调整 WispTerm Remote 网页控制台版本。
