# WispTerm v1.34.2

> Patch release adding Kimi Code session history and improving tmux 2.7
> compatibility. No configuration migration is required.

## Added

- **Kimi Code session history (#592).** The AI history browser now reads current
  and migrated Kimi Code sessions on Local, WSL, and SSH targets. It combines
  Kimi's wire, state, and session-index data for transcript preview and resumes
  sessions in their recorded project directory with `kimi --session`. This
  replaces the previous Reasonix integration.

## Fixed

- **tmux 2.7 TUI reattach (#591).** tmux control-mode bootstrap commands now use
  printable separators that survive an outer SSH TTY, and terminal input uses
  hexadecimal key names supported by tmux 2.7 and newer. Reattached full-screen
  TUIs recover keyboard and mouse input on older servers.

## Compatibility

- Existing Codex and Claude Code history support is unchanged.
- Reasonix history is no longer listed; Kimi Code takes its provider slot.
- This is a desktop-only release; WispTerm Remote web console versions are not
  changed.

# WispTerm v1.34.2（中文）

> 本次补丁发布新增 Kimi Code 会话历史，并改善 tmux 2.7 兼容性；无需迁移配置。

## 新增

- **Kimi Code 会话历史（#592）。** AI 历史浏览器现在可读取本地、WSL 与 SSH 目标上
  新旧格式的 Kimi Code 会话。WispTerm 会合并 Kimi 的 wire、state 与会话索引数据，
  用于预览对话，并通过 `kimi --session` 在历史记录的原始项目目录中恢复会话。
  该功能替代原有的 Reasonix 集成。

## 修复

- **tmux 2.7 TUI 重连（#591）。** tmux control-mode 启动命令改用可安全通过外层
  SSH TTY 的可打印分隔符，终端输入则改用 tmux 2.7 及更高版本支持的十六进制键名。
  在较旧服务器上重连全屏 TUI 后，键盘与鼠标输入可以正确恢复。

## 兼容性

- 现有 Codex 与 Claude Code 历史支持保持不变。
- AI 历史浏览器不再列出 Reasonix，由 Kimi Code 占用对应 provider 位置。
- 本次仅发布桌面应用，不调整 WispTerm Remote 网页控制台版本。
