# WispTerm v1.35.3

> Patch release so clicking a Windows task-complete toast focuses WispTerm.
> No configuration migration is required.

## Fixed

- **Windows toast click focus (#597).** Clicking a desktop notification for a
  finished Task/Run now restores and focuses the WispTerm window. Toast
  callbacks now decode the Windows 10+ `NOTIFYICON_VERSION_4` layout, register
  the tray icon against the real window, and force the window to the
  foreground.

## Compatibility

- Existing settings and workflows require no changes.
- This is a desktop-only release; WispTerm Remote web console versions are not
  changed.

# WispTerm v1.35.3（中文）

> 本次补丁发布修复 Windows 任务完成通知点击后无法回到 WispTerm 的问题；

## 修复

- **Windows 通知点击聚焦（#597）。** 点击任务/Run 结束后的桌面通知，现在会
  恢复并聚焦 WispTerm 窗口。通知回调已按 Windows 10+ 的
  `NOTIFYICON_VERSION_4` 布局解析，托盘图标注册到真实窗口，并在点击时将
  窗口强制切到前台。

## 兼容性

- 本次仅发布桌面应用，不调整 WispTerm Remote 网页控制台版本。
