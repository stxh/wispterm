# WispTerm v1.35.1

> Patch release improving macOS build compatibility and Metal renderer
> stability. No configuration migration is required.

## Fixed

- **macOS Intel Metal crash (#594).** Corrected the alignment declaration for
  per-thread Metal buffer, texture, pipeline, and sampler registries. This
  prevents the alignment fault that could crash Release builds when opening the
  Agent tab on Intel Macs, and lets Debug builds start without the previous
  alignment-sanitizer panic.
- **Command Line Tools-only macOS builds (#594).** WispTerm now requests
  Ghostty's `libghostty-vt`-only dependency mode and explicitly disables
  Ghostty's unused XCFramework and macOS app artifacts. Developers can build
  WispTerm with Apple's Command Line Tools without also installing the iOS SDK
  from the full Xcode application.

## Compatibility

- Existing Windows and experimental Linux builds continue to use the same
  renderer and platform paths; the Metal bridge change is compiled only for
  macOS.
- Existing settings and workflows require no changes.
- This is a desktop-only release; WispTerm Remote web console versions are not
  changed.

# WispTerm v1.35.1（中文）

> 本次补丁发布改善 macOS 构建兼容性与 Metal 渲染稳定性；
> 无需迁移配置。

## 修复

- **macOS Intel Metal 崩溃（#594）。** 修正 Metal buffer、texture、pipeline 与
  sampler 的线程本地注册表对齐声明，避免 Release 版在 Intel Mac 上
  打开 Agent 标签时因对齐故障崩溃，并使 Debug 版不再于启动时触发
  alignment sanitizer panic。
- **仅安装 Command Line Tools 的 macOS 构建（#594）。** WispTerm 现在
  对 Ghostty 依赖启用仅 `libghostty-vt` 模式，并显式关闭未使用的
  XCFramework 和 Ghostty macOS 应用产物。开发者只安装 Apple Command Line
  Tools 也可构建 WispTerm，无需为 iOS SDK 安装完整 Xcode。

## 兼容性

- 现有 Windows 与实验性 Linux 构建仍使用原有渲染器与平台路径；
  Metal 桥接层改动仅在 macOS 上编译。
- 现有设置与工作流无需修改。
- 本次仅发布桌面应用，不调整 WispTerm Remote 网页控制台版本。
