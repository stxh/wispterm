# WispTerm v1.34.1

> Patch release focused on terminal-session reliability and remote Agent file
> writing. No major features or configuration migrations are required.

## Fixed

- **tmux TUI reattach (#590).** Reattached tmux control-mode sessions now reseed
  the pane screen and restore terminal state, so full-screen TUIs and mouse
  behavior return correctly after reconnecting.
- **macOS keypad Enter and shutdown stability (#588).** The keypad Enter key now
  acts as Enter. Memory Digest scheduling is also synchronized and can be safely
  torn down after configuration reloads or application shutdown.
- **Remote Agent script writes (#589).** The Agent now uses `write_file` instead
  of shell heredocs for multiline files and scripts in SSH/WSL sessions,
  including large or temporary scripts. This avoids an interactive remote shell
  waiting for a missing heredoc terminator.

## Compatibility

- Existing settings and workflows continue to work unchanged.
- This is a desktop-only release; WispTerm Remote web console versions are not
  changed.

# WispTerm v1.34.1（中文）

> 本次为补丁发布，重点修复终端会话可靠性与远程 Agent 写文件问题；不含重大功能，
> 无需迁移配置。

## 修复

- **tmux TUI 重连（#590）。** tmux control-mode 会话重连后会重新同步面板屏幕并恢复
  终端状态，全屏 TUI 和鼠标行为可正确恢复。
- **macOS 小键盘 Enter 与退出稳定性（#588）。** 小键盘 Enter 现在与普通 Enter 一致。
  Memory Digest 调度器也已加锁，可在配置重载和应用退出后安全清理。
- **远程 Agent 写脚本（#589）。** Agent 在 SSH/WSL 会话中写入多行文件和脚本时，
  包括大型或临时脚本，都会使用 `write_file` 而非 shell heredoc，避免远程交互式
  shell 因缺少 heredoc 结束标记而卡住。

## 兼容性

- 现有设置和工作流无需变更。
- 本次仅发布桌面应用，不调整 WispTerm Remote 网页控制台版本。
